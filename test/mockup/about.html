About M@TE

M@TE is designed to meet geoscientists where they are: from educators and students using visualisations in the classroom to researchers developing and benchmarking new numerical models. It lowers the learning curve of numerical models and bridges the gap between traditional geology and numerical geosciences.

How M@TE works

M@TE combines a user-friendly experience with a robust backend built on widely adopted, sustainable infrastructure. Users browse model summaries through the website, which links to GitHub and NCI repositories for downloading code and outputs. Behind the scenes, carefully chosen tools ensure consistency, accessibility and long-term preservation.

Packaging

RO-Crates

Model metadata is packaged using the RO-Crate standard, a lightweight JSON-LD format that captures rich metadata and references model components. This keeps models machine-readable and FAIR.

Submission

GitHub

Models are submitted through structured GitHub issue templates. Metadata is validated and enriched automatically, connecting to Crossref, DataCite and ORCID.

Showcasing

Quarto

The website is built with Quarto, a scientific publishing system that delivers a fast, lightweight interface with figures, animations and interactive content.

Storage

NCI GeoNetwork

Model outputs are stored and preserved through NCI's GeoNetwork, which supports terabyte-scale data, assigns persistent DOIs and makes models discoverable through standard catalogue services.
